Chalakuzhy Family Register

Relationship Finder

Trace the shortest thread of kinship between any two members

This app talks to the Chalakuzhy Family Register API — set API_BASE_URL at the top of the <script> block below to your deployed API's URL. Unlike an earlier version of this tool, no database password is stored in this page — Neo4j Aura credentials live only on the backend server, so this file is safe to install on any family member's phone. Name matching is fuzzy (typo-tolerant) — if a name matches more than one person, you'll be asked to pick which one you meant before the relationship search runs.
